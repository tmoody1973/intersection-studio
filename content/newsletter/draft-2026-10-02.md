## What we learned

A detached HEAD in git means you're committing to a branch that doesn't belong to any named reference. The work is real — it gets SHA hashes, it writes to disk — but it has no home. If you switch branches without saving a reference, it eventually gets garbage collected. This week's merge was a rescue operation: five days of automated log entries that existed in the repository's history but had drifted off the main branch.

The automated log is faithful. It fires every day, writes the truth about the studio's state, commits the result. It ran for five days without anyone noticing it was writing to nowhere.

That's not a criticism of the automation — the system worked as designed. It's more of an observation about what "working" means when the output has no audience. The log entries were accurate. They named the same three unblocked actions they name every day. They noted the 160-day dormancy milestone. They were correct and complete and unread.

There's a version of this that maps onto the newsletter queue pretty directly.

## Deep dive: 165 days and what it costs

165 days is five and a half months. It's the whole summer plus two weeks. It's longer than most product sprints, longer than most hiring cycles, longer than most funding rounds.

The daily log has been running this whole time. It names the same blockers every day, increments the counter, and commits. The Studio Dashboard is live and healthy. The Mastra agents are running. The MKE Dashboard hasn't degraded — the data is still accurate, the code still works, the design still holds.

But there are costs that don't show up in git history.

The Mastra agents have P1 security items — HMAC replay protection and prompt injection hardening — that have been open for 27 weeks. A running AI system with a documented, unaddressed attack surface isn't a maintenance item that can wait indefinitely. The longer it runs, the longer the window. That's not a metaphor, it's just how exposure works.

The MKE Dashboard has a narrower civic window than it did 165 days ago. The HOLC redlining overlay, the neighborhood-level metrics, the multilingual access — those features were built for a Milwaukee that needs better public data tools. That need is still real. But tools exist in time. A civic data product launched in the moment it was built for is a different thing than the same product launched after the moment has passed.

Canvas Copilot is now in the territory where the story of the project risks becoming "we built a prototype and sat on it for two years." That's not a story. That's just a timestamp.

None of this is irreversible. The tracks aren't lost. The MKE Dashboard still deploys in one command. The newsletter drafts still send in one email. The Canvas Copilot decision still takes one conversation.

The counter is at 165. It will be at 172 next week.
