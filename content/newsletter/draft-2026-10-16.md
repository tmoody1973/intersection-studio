## What we learned

The gap between "healthy" and "secure" is not the same gap.

The Studio Dashboard is live. The Mastra agents respond at `intersection-mastra.fly.dev/health`. The automated systems fire on schedule. From the outside, everything looks operational.

But "operational" and "secured" are different things. The Mastra P1 security items — HMAC replay protection and prompt injection hardening — have been open for 38 weeks. That number is notable: it means these vulnerabilities have been known since early January 2026. The agents have been running, publicly exposed, for the entire stretch the studio has been dormant.

A green health endpoint doesn't mean the system is hardened. It means it's running. Those are different claims.

## Deep dive: security debt is still debt

Technical debt is a term people use loosely. Usually it means code written fast that will get cleaned up later. It's about maintainability. It's about the future.

Security debt is different. Security debt is a present-tense exposure, not a future-tense inconvenience.

The Mastra agents have been running in production with two known P1 vulnerabilities for 38 weeks. HMAC replay protection means an attacker who intercepts a valid request can replay it to trigger unauthorized actions. Prompt injection hardening means a malicious input could redirect agent behavior in ways it shouldn't. Neither of these is theoretical. Both are documented attack vectors for AI agent systems.

The reason they're still open isn't that no one knows how to fix them. The reason is that the studio has been dormant, and dormant studios don't ship security patches.

This is a cost of extended dormancy that the daily log doesn't capture clearly: it's not just that products sit undeployed. It's that deployed products continue accumulating risk while nobody is maintaining them. The MKE Dashboard is undeployed — it has no attack surface yet. Canvas Copilot is idle — it carries only the cost of indecision. But the Mastra agents are live, publicly accessible, and running with known vulnerabilities that have been open longer than the studio has been dormant.

The radio metaphor that runs through this studio's work is useful here. Dead air on the broadcast side is bad — silence where there should be signal. But leaving a transmitter running unsecured is worse than dead air. You're still broadcasting. You just have no idea what.

The dashboard is green. That's not the same as safe.

At six months of dormancy, the MKE Dashboard and the newsletter queue are stories about delayed shipping. The Mastra security debt is a different story. It's the one that gets worse the longer it waits.
