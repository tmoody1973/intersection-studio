## What we learned

A P1 security vulnerability left open on a live system isn't technical debt. It's a present-tense risk with a real address.

The Mastra agents at `intersection-mastra.fly.dev` have had two open P1s for 49 weeks: HMAC replay protection and prompt injection hardening. Both are unaddressed. The system is still running.

49 weeks is almost a year. That number deserves some attention.

A P1 isn't a "would be good to fix" item. It's the designation for a vulnerability that could cause real harm to real users right now. HMAC replay means an attacker can intercept and reuse valid requests. Prompt injection means an attacker can manipulate the AI agents' behavior through crafted input. On a live system serving actual users, these aren't hypothetical. They're exposure.

The studio methodology says "ship over perfect." That's a good principle for product decisions — don't wait for polish when speed matters more. It's a terrible principle for security. You can't ship and iterate on a system that's been exploited.

The two-month rule in security practice: any critical vulnerability open longer than 60 days has effectively been accepted as permanent. At 49 weeks, that window closed 37 weeks ago.

## Deep dive: what does 49 weeks mean

The Mastra P1s were first logged in mid-November 2025. That's when the security review flagged HMAC replay as exploitable and prompt injection as an active surface. Both got written up. Both got put on the backlog. Neither got fixed.

Here's the uncomfortable math: a product studio that builds civic tech and cultural tools is running a live AI system with a prompt injection vulnerability for 49 weeks. The Mastra agents are the studio's most visible technical infrastructure. They're what demonstrates that the studio can build and run production AI systems, not just prototype them.

Prompt injection on an AI agent isn't like an XSS vulnerability on a static website. XSS lets an attacker run JavaScript in a visitor's browser — bad, but bounded. Prompt injection lets an attacker redirect what an AI system does — what it says, what it accesses, what it outputs. The blast radius depends on what the agent has access to. That's an open question here, which is itself a problem.

The culture/technology intersection that the studio is built around runs in both directions. Technology can amplify culture — which is what Crate, MKE Dashboard, and the Mastra agents are trying to do. But it can also extract from it: bad actors using a misconfigured AI system to generate harmful outputs, manipulate users, or access data they shouldn't. 

A studio that talks publicly about responsible AI and civic technology running a system with known P1s for nearly a year is a credibility gap. Not in a PR sense — in a practice-what-you-preach sense. The fix isn't complicated. The delay is.

The HMAC replay fix is a signing scheme update. The prompt injection hardening is input validation and output filtering. Neither requires external dependencies or a major refactor. Both require someone to make the time.

That's the honest state of it.
